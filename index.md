# GBE — Generative Being Externalized

A trilogy in three papers, one runnable cognitive instrument, and four frozen experiment tracks.

## Start in 5 Minutes

```powershell
git clone https://github.com/JackeyLGene/GBE.git
cd GBE
python docs\quickstart_geruon.py
python docs\quickstart_ee_self.py
```

No `pip install` required. Python 3.8+ stdlib only.

## What This Is

GBE is a centroid detector with memory pressure. The instrument repeatedly applies two operations — merge similar frames, prune unreinforced frames — under finite memory. Those operations converge streams into structural centroids.

The same core instrument is used across four domains:

|--------|-------------|
| UN diplomatic voting | 2025 displacement rank 1/79 |
| Bach WTC | Transposition equivariance 100% |
| DNA alignments | Exon/intron d=-0.97 |
